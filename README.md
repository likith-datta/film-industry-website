# 🎬 CineVerse - Global Film Industries & Top 10 Actors Showcase

An interactive, responsive web experience exploring leading film industries worldwide and showcasing their top 10 iconic actors with rich media, biographies, notable filmographies, interactive 3D/carousel loop views, and grid mode.

## 🌟 Key Features

- **Global Film Industries**: Navigate through prominent cinematic industries including Tollywood, Bollywood, Kollywood, Sandalwood, Mollywood, Hollywood, and more.
- **Top 10 Actors Per Industry**: Curated profiles with real portrait photography, signature titles, biographical extracts, and key film credits.
- **Dynamic Showcase Modes**:
  - **Loop / Carousel View**: Smooth auto-looping interactive showcase with speed controls, pause/resume, and keyboard navigation.
  - **All 10 Grid View**: Full overview of all 10 actors with quick filtering and modal inspection.
- **Interactive Actor Detail Modal**: High-res portraits, complete bios, career highlights, and top movies.
- **Sound Effects & Ambient Theme**: Built-in sound toggle with Web Audio synthesizer feedback and modern dark-mode cinematic glow aesthetics.
- **Mobile Responsive**: Seamless touch and swipe gestures tailored for mobile, tablet, and desktop displays.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve
```

Then visit `http://localhost:8000` in your browser.
